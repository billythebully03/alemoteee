# Фронтенд (стартовый каркас)

Чёрный фон, одна лента, кнопка меню и кнопка создания. Данных, сохранения и бэкенда пока нет.

## Запуск

```bash
npm install
npm run dev
```

## Структура

```
src/
  main.tsx              точка входа, подключение стилей
  App.tsx               корень приложения, здесь подключаются экраны
  config/app.ts         название, тексты, ограничения. Менять здесь
  shared/ui/            общие компоненты, которые используются в нескольких местах
  features/             всё, что относится к конкретной функции
    feed/               лента
    menu/               меню (поиск и профиль появятся здесь)
    recorder/           создание видео
  styles/global.css     базовые стили и цветовые переменные
```

## Правила, которые помогут не запутаться

- Один экран или функция — одна папка в `features/`.
- Компонент попадает в `shared/` только тогда, когда используется в двух местах и больше.
- Тексты и числа, которые могут меняться, лежат в `config/app.ts`.
- Цвета берутся из переменных в `global.css`, а не пишутся прямо в компонентах.
